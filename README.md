# P-kensa — 歯周検査アプリ

はた歯科医院の歯周検査アプリ（単一HTML・外部依存ゼロ）。

- 配信: GitHub Pages（このリポジトリの index.html）。**URLは変えないこと**（保存データは配信URLごとに分かれるため）
- データはアプリ内に含まれません（各端末の IndexedDB に保存）
- 更新方法: index.html を上書きして push
- sw.js: 回線が落ちていても最後に開けた版でアプリを開くための仕組み（ネット優先なので、ふだんは必ず最新の版を読む）。止めるときは sw.js の中身を「登録を解除するだけ」のものに差し替えて push する
